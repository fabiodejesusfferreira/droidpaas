# Identidade visual

Logo do **droidpaas**: uma cabeça de robô em domo (com antenas) sobre um rack de servidor; os olhos são o prompt `>_` do terminal.

| Arquivo | Para quê |
|---|---|
| `icon.svg` | Ícone sobre fundo claro |
| `icon-dark.svg` | Ícone sobre fundo escuro |
| `icon-app.svg`, `icon-512.png`, `icon-192.png`, `favicon-32.png` | Ícone de app/avatar (quadrado arredondado) |
| `wordmark.svg`, `wordmark-dark.svg` | Ícone + nome (texto convertido em contornos) |
| `social-preview.png` | Imagem de compartilhamento do GitHub (1280×640) |

Cores: azul `#0B5FFF` (claro) / `#5B8CFF` (escuro), tinta `#0B1220`. Tipografia do nome: Noto Sans Bold (SIL OFL), já convertida em contornos.

## Política de uso da marca

O **código** deste repositório é MIT (veja `LICENSE`). **O nome "droidpaas" e estes arquivos de logo não estão sob a licença MIT**: são marca e arte do projeto, todos os direitos reservados.

- Pode: citar o projeto pelo nome, usar a logo para **indicar que você usa ou fala sobre** o droidpaas (artigos, vídeos, tutoriais, páginas de "feito com") e usá-la em forks **apenas para apontar para o projeto original**.
- Não pode: usar o nome ou a logo de um jeito que sugira que seu produto, fork ou serviço é o droidpaas oficial ou é endossado por ele, nem alterar a logo para esse fim.
- Fork que segue como projeto próprio deve ter **outro nome e outra logo**.

Em caso de dúvida, abra uma issue.
